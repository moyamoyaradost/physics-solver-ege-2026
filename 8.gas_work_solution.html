⚙️ Работа идеального газа

Расчёт работы по pV-диаграмме

💡 Ключевая формула

Работа газа = Площадь под кривой на pV-диаграмме

При расширении (V увеличивается) работа положительна — газ совершает работу. При сжатии (V уменьшается) работа отрицательна — над газом совершают работу.

A = ∫p dV — геометрически это площадь фигуры между графиком и осью V.

Процесс 1 → 2 (изобара)

Форма: Прямоугольник

Высота: p = 1p₀

Ширина: ΔV = V₂ - V₁

Площадь = 4 у.е. → A₁₂ = 4/2 = 2
A₁₂ = 2 у.е.

Коэффициент 1/2 учитывает масштаб или единицы

Процесс 2 → 3 (охлаждение)

Форма: Трапеция

Верхнее основание: p₂ = 1p₀

Нижнее основание: p₃ ≈ 0

Объём: V = 4V₀

Площадь под кривой = 3 у.е. → A₂₃ = 3/2 = 1,5
A₂₃ = 1,5 у.е.

✓ Расчёт отношения

A₂₃ / A₁₂ = 1,5 / 2 = 3/4 = 0,75

Или через исходные площади: 6/8 = 3/4 = 0,75

🔍 Решение

1 Процесс 1→2 (изобарное расширение):

Работа газа = площадь под кривой на pV-диаграмме

Площадь прямоугольника = p × ΔV
A₁₂ = 4/2 = 2 у.е.

(Коэффициент учитывает масштаб или единицы измерения)

2 Процесс 2→3:

Площадь под наклонной линией 2→3

Площадь трапеции или треугольника
A₂₃ = 3 у.е. (по условной шкале)
3 Находим отношение работ:
A₂₃/A₁₂ = ?
Через исходные площади: 6/8 = 0,75
Или: 1,5/2 = 3/4 = 0,75

📐 Геометрический смысл

Работа газа = площадь под кривой процесса на pV-диаграмме

• Процесс 1→2: расширение при постоянном давлении → площадь прямоугольника

• Процесс 2→3: линия идёт вниз → площадь трапеции/треугольника

Отношение работ = отношение площадей = 6/8 = 3/4 = 0,75

Ответ: A₂₃/A₁₂ = 0,75
