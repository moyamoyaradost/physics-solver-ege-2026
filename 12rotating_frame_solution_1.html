💡 Магнитный поток через рамку

Магнитный поток Φ через поверхность площадью S в однородном магнитном поле с индукцией B:

Φ = B · S · cos(α)

где α — угол между вектором B и нормалью к поверхности рамки.

При вращении рамки с угловой скоростью ω: α = ωt → Φ = BS·cos(ωt)

🔍 Решение

1 Общая формула магнитного потока при вращении:
Φ(t) = B · S · cos(ωt)

где B — индукция, S — площадь рамки, ω — угловая скорость

2 Сравниваем с данным законом:
Φ(t) = 4·10⁻⁷ · cos(100πt) Вб

Максимальное значение потока (амплитуда):

Φmax = B · S = 4×10⁻⁷ Вб
3 Находим площадь рамки:
S = Φmax / B
S = (4×10⁻⁷ Вб) / (2×10⁻³ Тл)
S = 2×10⁻⁴ м² = 2 см²
4 Проверка размерности:

[S] = [Φ]/[B] = Вб/Тл = (Тл·м²)/Тл = м² ✓

2×10⁻⁴ м² = 2×10⁻⁴ × 10⁴ см² = 2 см²

⚙️ Физический смысл

Рамка площадью 2 см² (примерно 1,4×1,4 см) вращается с частотой ν = ω/(2π) = 100π/(2π) = 50 Гц (50 оборотов в секунду) в магнитном поле с индукцией 2 мТл.

Магнитный поток меняется от +4×10⁻⁷ Вб (рамка перпендикулярна полю) до -4×10⁻⁷ Вб (рамка развернулась на 180°), проходя через ноль (рамка параллельна полю).

Ответ: S = 2 см²
