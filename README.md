## 🔧 Модули проекта

### Модуль утилит Canvas (`canvas-utils.js`)

Предоставляет безопасные функции для работы с Canvas API:

- `getCanvas(id)` - безопасное получение элемента Canvas
- `getContext(id)` - безопасное получение контекста 2D
- `drawArrow(...)` - рисование стрелок и векторов
- `drawAxes(...)` - рисование координатных осей
- `safeDivide(...)` - защита от деления на ноль
- `safeFind(...)` - безопасный поиск в массивах
- `safeAnimate(...)` - безопасная анимация с проверкой видимости

**Пример использования:**
```javascript
<script src="canvas-utils.js"></script>
<script>
    const canvas = getCanvas('myCanvas');
    if (!canvas) return;
    const ctx = getContext('myCanvas');
    if (!ctx) return;
    
    drawAxes(ctx, 50, canvas.width, canvas.height, 'Время, с', 'Скорость, м/с');
</script>
```

### Модуль общих стилей (`common.css`)

Содержит общие стили для всех компонентов:
- Базовые стили (reset, body, container)
- Компоненты интерфейса (header, content, cards)
- Компоненты решения (solution-section, step, formula-box)
- Анимации (pulse, transitions)

**Пример использования:**
```html
<link rel="stylesheet" href="common.css">
<style>

        max-width: 1400px;
    }
</style>
```
