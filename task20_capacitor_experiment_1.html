🔬 Задача №20: Эксперимент с конденсатором

Исследование зависимости ёмкости от площади пластин

💡 Ёмкость плоского конденсатора

Формула ёмкости: C = ε₀·ε·S / d

где:

• ε₀ — электрическая постоянная

• ε — диэлектрическая проницаемость

• S — площадь пластин

• d — расстояние между пластинами

Вывод: C ∝ S (при ε и d постоянных)

🎯 Метод исследования зависимости

Золотое правило эксперимента:

Чтобы проверить влияние ОДНОГО параметра, нужно:

✓ Изменить ТОЛЬКО этот параметр

✓ Все остальные параметры оставить НЕИЗМЕННЫМИ

Для нашей задачи:

• Меняем: Площадь S

• Оставляем неизменными: Расстояние d и Диэлектрик ε

🔍 Решение

1 Определяем цель эксперимента:

Нужно исследовать зависимость ёмкости C от площади пластин S

C = f(S) при const(d, ε)
2 Определяем требования к выбору:

Нужны два конденсатора с:

✓ РАЗНОЙ площадью S

✓ ОДИНАКОВЫМ расстоянием d

✓ ОДИНАКОВЫМ диэлектриком ε

3 Проверяем все пары:

Конденсаторы 1-2: d разное ❌

Конденсаторы 1-3: S одинаковое ❌

Конденсаторы 1-4: d и диэлектрик разные ❌

Конденсаторы 1-5: d разное ❌

Конденсаторы 2-5: S разное (200≠300), d одинаковое (0.4), диэлектрик одинаковый (парафин) ✓

4 Ответ:
Конденсаторы №2 и №5 → 25

⚙️ Почему именно эти?

Конденсаторы №2 и №5 — идеальная пара для эксперимента!

• Площадь меняется: 200 см² → 300 см² (в 1.5 раза)

• Ожидаем: C₅ / C₂ = S₅ / S₂ = 300/200 = 1.5

Все остальные пары НЕ подходят:

• 1-2, 1-4, 1-5: разное расстояние d

• 1-3: одинаковая площадь (не проверим зависимость!)

• 3-4, 3-5: разный диэлектрик

• 2-3, 2-4: разный диэлектрик

Ответ: 25
