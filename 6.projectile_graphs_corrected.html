Анализ графиков физических величин (ЕГЭ 2026)

График А: Парабола "ВВЕРХ" ∪
График Б: Горизонтальная линия

💡 Ключевые моменты движения

При броске под углом к горизонту:

  • Вертикальная скорость vy меняется линейно: vy = v0sin(α) - gt
  • Горизонтальная скорость vx постоянна: vx = v0cos(α)
  • Ускорение ay постоянно: ay = -g
  • В верхней точке vy = 0, но vx ≠ 0 → vmin = vx

🔍 Анализ всех величин

1. Потенциальная энергия Ep

Ep = mgy(t)
Поведение: y(t) = h + v0yt - gt²/2 — это парабола, но Ep отсчитывается от y=0, поэтому Ep = mg(h + v0yt - gt²/2) — парабола «вниз» (максимум в начале).

2. Проекция импульса py

py = mvy = m(v0sin α - gt)
Поведение: Линейно убывает (наклонная прямая). Изначально положительна, проходит через ноль в верхней точке, затем отрицательна.

3. Проекция ускорения ay

ay = -g = const
Поведение: Постоянная отрицательная величина (горизонтальная линия ниже нуля). Не зависит от времени!

4. Кинетическая энергия Ek

Ek = mv²/2 = m(vx² + vy²)/2
Поведение: Парабола "ВВЕРХ" ∪ (минимум в верхней точке, где vy = 0). v² = vx² + (v0sinα - gt)² → коэффициент при t² положительный → парабола вверх!

⚡ Математическое доказательство

Почему Ek — парабола «ВВЕРХ»:

v² = vx² + vy² = (v₀cosα)² + (v₀sinα - gt)²

Раскрываем: v² = v₀²cos²α + v₀²sin²α - 2v₀sinα·gt + g²t²

v² = v₀² - 2v₀sinα·g·t + g²t²

Коэффициент при t² равен g² > 0 → парабола «ВВЕРХ» (∪-образная)!

Минимум в момент t = v₀sinα/g (когда vy = 0), где Ek,min = mvx²/2.

🔍 Почему не другие варианты?

График А не может быть:

  • Ep — парабола «вниз» (максимум в начале), не «вверх»
  • py — линейная функция (прямая), не парабола
  • ay — константа (горизонтальная линия), не парабола

График Б не может быть:

  • Ep, Ek, py — все они меняются со временем
  • Только ay = -g остаётся постоянной!
Ответ: А → 4, Б → 3
