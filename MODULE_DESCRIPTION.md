## 1. Модуль утилит Canvas (`canvas-utils.js`)

### 1.1 Назначение модуля
Модуль предоставляет набор утилитных функций для безопасной работы с HTML5 Canvas API. Обеспечивает единообразный подход к работе с графикой во всех задачах проекта.

### 1.2 Функциональные возможности
- Безопасное получение элементов Canvas
- Безопасное получение контекста 2D
- Очистка Canvas
- Рисование стрелок и векторов
- Рисование координатных осей
- Безопасная анимация с проверкой видимости
- Защита от деления на ноль
- Безопасный поиск в массивах

### 1.3 Интерфейс модуля

#### Функция: `getCanvas(id)`
**Назначение:** Безопасное получение элемента Canvas по ID

**Параметры:**
- `id` (string) - идентификатор элемента Canvas

**Возвращает:**
- `HTMLCanvasElement | null` - элемент Canvas или null при ошибке

**Пример использования:**
```javascript
const canvas = getCanvas('myCanvas');
if (!canvas) {
    console.error('Canvas не найден');
    return;
}
```

#### Функция: `getContext(id)`
**Назначение:** Безопасное получение контекста 2D для Canvas

**Параметры:**
- `id` (string) - идентификатор элемента Canvas

**Возвращает:**
- `CanvasRenderingContext2D | null` - контекст или null при ошибке

**Пример использования:**
```javascript
const ctx = getContext('myCanvas');
if (!ctx) {
    console.error('Контекст не получен');
    return;
}
```

#### Функция: `drawArrow(ctx, x1, y1, x2, y2, color, lineWidth, label)`
**Назначение:** Рисование стрелки на Canvas

**Параметры:**
- `ctx` (CanvasRenderingContext2D) - контекст Canvas
- `x1, y1` (number) - координаты начала
- `x2, y2` (number) - координаты конца
- `color` (string) - цвет стрелки (по умолчанию '#333')
- `lineWidth` (number) - толщина линии (по умолчанию 3)
- `label` (string) - подпись стрелки (опционально)

**Пример использования:**
```javascript
drawArrow(ctx, 100, 100, 200, 200, '#ff0000', 3, 'Сила F');
```

#### Функция: `safeDivide(numerator, denominator, defaultValue)`
**Назначение:** Безопасное деление с защитой от деления на ноль

**Параметры:**
- `numerator` (number) - числитель
- `denominator` (number) - знаменатель
- `defaultValue` (number) - значение по умолчанию (по умолчанию 0)

**Возвращает:**
- `number` - результат деления или значение по умолчанию

**Пример использования:**
```javascript
const result = safeDivide(10, 0, 0); // Вернет 0 вместо ошибки
```

### 1.4 Принципы проектирования
