💧 Насыщенный пар под поршнем

Изотермическое сжатие при постоянной температуре

🔑 КЛЮЧЕВОЙ ПРИНЦИП: pнасыщ зависит ТОЛЬКО от T → при T=const → p=const

💡 Что такое насыщенный пар?

Насыщенный пар — это пар, находящийся в динамическом равновесии со своей жидкостью. Число молекул, испаряющихся с поверхности жидкости, равно числу молекул, конденсирующихся обратно.

В состоянии равновесия скорость испарения = скорость конденсации. Это равновесие зависит только от температуры!

⚗️ Свойства насыщенного пара

1. Давление: pнас = p(T) — функция только температуры

2. Концентрация: n = p/(kT) — при T=const и p=const → n=const

3. При сжатии: часть пара конденсируется, p и n не меняются

4. При расширении: часть жидкости испаряется, p и n не меняются

🔍 Решение

1 Давление насыщенного пара:

Давление насыщенного пара зависит ТОЛЬКО от температуры:

pнас = f(T)

Температура не меняется (медленный процесс, контакт с жидкостью) → T = const

pнас = const → НЕ ИЗМЕНИТСЯ (3)
2 Концентрация молекул пара:

Из уравнения состояния идеального газа:

p = nkT, где n = N/V — концентрация

При T = const и p = const:

n = p/(kT) = const

Что происходит физически: V↓ → часть пара конденсируется → N↓ пропорционально V↓ → n = N/V = const

n = const → НЕ ИЗМЕНИТСЯ (3)
3 Что изменяется:

При сжатии изменяются:

• Объём V — уменьшается
• Число молекул пара N — уменьшается (конденсация)
• Масса жидкости — увеличивается

Но соотношение n = N/V остаётся постоянным!

🔬 Динамическое равновесие

При сжатии:

1. Поршень опускается → объём уменьшается

2. Концентрация молекул пара временно растёт → давление начинает расти

3. Скорость конденсации становится больше скорости испарения

4. Избыточные молекулы конденсируются в жидкость

5. Устанавливается новое равновесие с теми же p и n, но меньшим N

✓ Ответ

Давление пара: 3 (не изменится)

Концентрация молекул: 3 (не изменится)

Ответ: 3 3
