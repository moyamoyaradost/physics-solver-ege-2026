💡 Колебания в LC-контуре

Заряд конденсатора: q(t) = qmax·cos(ωt + φ)

Ток в катушке: i(t) = dq/dt = -qmax·ω·sin(ωt + φ)

Энергия электрического поля: WC = q²/(2C) ~ cos²(ωt)

Энергия магнитного поля: WL = Li²/2 ~ sin²(ωt)

Ключевой факт: Когда q максимален → i = 0, WC макс, WL = 0

Когда q = 0 → i максимален, WC = 0, WL макс

✅❌ Проверка утверждений

1. Период колебаний равен T = 8·10⁻⁶ с. ✓ ВЕРНО
Анализ таблицы: q(0) = 1·10⁻⁹ Кл, q(8) = 1·10⁻⁹ Кл — заряд вернулся к исходному значению. Полный цикл колебаний занял 8·10⁻⁶ с, следовательно T = 8·10⁻⁶ с.
2. Частота колебаний равна ν = 250 кГц. ✗ НЕВЕРНО
Расчёт: ν = 1/T = 1/(8×10⁻⁶) = 125 000 Гц = 125 кГц ≠ 250 кГц. Утверждение неверно.
3. В момент времени t = 2·10⁻⁶ с модуль силы тока в катушке максимален. ✓ ВЕРНО
Из таблицы: q(2) = 0. В колебательном контуре ток i = dq/dt. Когда заряд проходит через ноль (q=0), его производная (скорость изменения) максимальна → |i| максимален.
4. В момент времени t = 8·10⁻⁶ с энергия магнитного поля катушки максимальна. ✗ НЕВЕРНО
Из таблицы: q(8) = 1·10⁻⁹ Кл (максимальное значение). WL = Li²/2 максимальна при imax, что происходит при q=0. При q=max ток i=0, следовательно WL=0 (минимальна).
5. В момент времени t = 4·10⁻⁶ с энергия электрического поля конденсатора минимальна. ✗ НЕВЕРНО
Из таблицы: q(4) = -1·10⁻⁹ Кл. WC = q²/(2C) зависит от q². При q(4)=-1 имеем |q|=1 (максимум) → WC максимальна. Энергия минимальна при q=0, например при t=2 или t=6.

⚙️ Сдвиг фаз между q и i

q(t) и i(t) колеблются с разностью фаз π/2 (90°):

• Когда q = max → i = 0

• Когда q = 0 → i = max

• Когда q = min → i = 0

Энергии: WC + WL = const (закон сохранения энергии)

Ответ: утверждения 1 и 3 верны
