## 6. Реализация модулей

### 6.1 Модуль утилит Canvas

**Файл:** `canvas-utils.js`  
**Строк кода:** ~230  
**Функций:** 8

**Реализованные функции:**
- `getCanvas(id)` - безопасное получение Canvas
- `getContext(id)` - безопасное получение контекста
- `clearCanvas(...)` - очистка Canvas
- `drawArrow(...)` - рисование стрелок
- `drawAxes(...)` - рисование осей
- `safeAnimate(...)` - безопасная анимация
- `safeDivide(...)` - защита от деления на ноль
- `safeFind(...)` - безопасный поиск

**Особенности:**
- Проверка всех входных данных
- Обработка ошибок с логированием
- JSDoc документация

### 6.2 Модуль общих стилей

**Файл:** `common.css`  
**Строк кода:** ~210  
**Классов:** 15+

**Реализованные компоненты:**
- Базовые стили (reset, body, container)
- Компоненты интерфейса (header, content, cards)
- Компоненты решения (solution-section, step, formula-box)
- Анимации (pulse, transitions)

**Особенности:**
- Убрано ~4000 строк дублирования
- Единообразный стиль
- Адаптивность

### 6.3 Модули задач

#### Пример использования утилит:
```javascript
// Безопасное получение Canvas
const canvas = getCanvas('myCanvas');
if (!canvas) return;
const ctx = getContext('myCanvas');
if (!ctx) return;

// Рисование осей
drawAxes(ctx, 50, canvas.width, canvas.height, 'Время, с', 'Скорость, м/с');

// Безопасное деление
const result = safeDivide(10, 0, 0); // Вернет 0 вместо ошибки
```
