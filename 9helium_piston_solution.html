⚗️ Гелий в цилиндре с подвижным поршнем

Изобарный процесс при постоянном давлении

🔑 КЛЮЧЕВОЙ ПРИНЦИП: Поршень подвижен без трения → pгаза = pатм = const

💡 Физическая модель

Условие равновесия поршня: Сила давления газа снизу = Сила атмосферного давления сверху + Вес поршня

pгаза·S = pатм·S + mg

Поскольку поршень движется без трения, при любом изменении температуры он перемещается так, чтобы сохранить это равновесие → давление газа остаётся постоянным (изобарный процесс).

⚙️ Закон Гей-Люссака (изобара)

V/T = const при p = const

Или: V = (νRT)/p

При нагреве (T↑) → объём увеличивается (V↑), поршень поднимается

При охлаждении (T↓) → объём уменьшается (V↓), поршень опускается

✅❌ Проверка утверждений

1. При сжатии гелия внешние силы совершают отрицательную работу. ✗ НЕВЕРНО
Факт: При сжатии поршень движется вниз. Внешние силы (pатм + вес поршня) направлены вниз, перемещение тоже вниз → работа положительная (A > 0). Работа газа при сжатии отрицательна, но работа внешних сил — положительна!
2. При медленном повышении температуры давление гелия увеличивается. ✗ НЕВЕРНО
Факт: Поршень подвижен без трения → давление газа всегда равно pатм = const. При нагреве увеличивается объём (поршень поднимается), а давление остаётся постоянным. Это изобарный процесс.
3. При медленном понижении температуры сила давления гелия на поршень не изменяется. ✓ ВЕРНО
Факт: Давление газа p = pатм = const (подвижный поршень). Сила F = p·S, где S — площадь поршня. Поскольку p и S постоянны, то F = const при любой температуре.
4. Если на поршень насыпать песок (температура прежняя), то после равновесия давление будет равно первоначальному. ✗ НЕВЕРНО
Факт: Добавили песок → вес поршня увеличился → для равновесия нужно большее давление газа: pновое = pатм + (mпескаg)/S > pатм. Объём уменьшится, давление увеличится (при T = const).
5. При медленном повышении температуры объём гелия увеличивается. ✓ ВЕРНО
Факт: Закон Гей-Люссака: V/T = const при p = const. При T↑ → V↑. Физически: молекулы движутся быстрее, оказывают большее давление, поршень поднимается до нового равновесия.

🔬 Важные выводы

1. Изобарный процесс: p = const, V/T = const

2. Подвижный поршень: автоматически поддерживает постоянное давление

3. При нагреве: V↑, поршень вверх, p = const

4. При охлаждении: V↓, поршень вниз, p = const

5. При добавлении груза: V↓, p↑ (новое равновесие)

Ответ: утверждения 3 и 5 верны
